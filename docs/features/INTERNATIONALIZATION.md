# 국제화와 에셋 디버그

## 언어와 설정

- 첫 실행 언어는 브라우저 언어와 관계없이 영어다.
- 메인 메뉴 설정과 게임 중 일시정지 설정에서 English / 한국어를 선택한다.
- 메뉴, 캐릭터 선택, HUD, 무기 이름·설명·능력치, 상호작용, 보급 알림,
  게임 종료 안내, 모바일 조작, 디버그 안내에 선택한 언어를 적용한다.
- 캐릭터 이름과 에셋 파일명·기술 식별자는 원문을 유지한다.
- 언어와 소리 설정은 `zombie-horde.settings.v1` localStorage 항목에 저장한다.
  저장된 설정은 같은 브라우저·사이트에서 다시 방문해도 유지된다.
- 저장소 접근이 차단되거나 저장값이 잘못되면 기본값으로 시작한다.
  저장 실패가 발생해도 현재 세션에서는 설정 변경을 적용한다.

## 구조

- `src/i18n/catalog.ts`: 영어 원문 키, 한국어 번역, 이름 있는 변수 치환.
- `src/systems/UserSettings.ts`: 설정 복원·저장과 런타임 언어 선택.
- `src/systems/SettingsPanel.ts`: 메인 메뉴와 일시정지가 공유하는 설정 UI.
- `src/logic/settingsLayout.ts`: 좁거나 짧은 화면에서도 제목과 버튼 간격을 보존하는 배치.
- HUD의 순수 표시 함수는 언어를 인자로 받는다. 전투 수치와 게임 판정은 번역하지 않는다.
- 새 UI 문구를 추가할 때 번역 사전에도 항목을 추가한다. 고유명사를 유지하는 경우에도
  명시적인 번역 항목으로 등록한다.

## 숨겨진 디버그 주소

게임 주소 뒤에 `?debug=assets`를 붙인다. 예: 로컬 개발 서버의
`http://localhost:5173/?debug=assets`. 배포 하위 경로에서도 같은 쿼리를 사용한다.
메인 메뉴에는 디버그 진입 버튼을 표시하지 않는다. 백엔드나 인증이 없는 클라이언트 화면이다.

- **Items**: 전체 무기 4종과 탄약·구급상자 4종. 실제 획득 오브젝트와 설정 수치를 표시한다.
- **Images / Sounds**: `src/assets`의 이미지와 오디오를 자동 발견한다.
  이미지 미리보기와 직접 재생 가능한 오디오 컨트롤을 제공한다.
- **Models & motion**: 남녀 플레이어, 일반·빠른 좀비의 외형 예시, 실제 맵의 전체 건물,
  월드, 보급 투하, 사격·피격·사망·상자 파괴·근접 효과를 확인한다.
- 플레이어는 모든 무기, 방향, 이동, 재생 속도, 경찰봉 모션 시간,
  총구 화염, 반동, 재장전 모션을 조절할 수 있다.
- 검색과 분류 필터를 제공하며 화면 상단 목록을 스크롤할 수 있다.
- `MAIN MENU`로 돌아가면 디버그 UI와 미리보기를 정리하고 URL에서 디버그 쿼리를 제거한다.
- 디버그 코드는 해당 주소로 접근할 때 지연 로드한다.

## 검증

- 설정 시스템 테스트: 기본값, 새 세션 복원, 손상된 저장값, 저장소 접근 실패.
- 번역 테스트: 문구별 변수 보존, 무기·캐릭터·소모품 번역 항목, 툴팁 번역.
- 배치 테스트: PC, 모바일 세로·가로에서 버튼과 제목의 겹침 방지.
- 실제 Chrome 자동 검증: 영어 기본값, 한국어 전환과 저장 복원, 소리 저장,
  게임 중 언어 변경, 디버그 미리보기·새로고침·종료, 치명적 런타임 오류 없음.
- 설정 화면 캡처 확인: 1280×800, 390×844, 568×320.

## 알려진 사항

- 실제 모바일 기기 검증은 수행하지 않았다. Chrome viewport 에뮬레이션으로 확인했다.
- 좀비 외형은 절차적으로 생성되므로 디버그 목록에는 고정 seed의 참고 변형을 표시한다.
- 기존 Phaser 번들의 500 kB 초과 빌드 경고가 남아 있다.
