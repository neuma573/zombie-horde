# 도심 건물 비주얼

## 상태

- 고정형 도심 맵의 후속 시각 작업
- Phaser 도형과 최소 런타임 노면 에셋 사용
- 충돌 및 hitscan 규칙은 변경하지 않으며 확장된 고정 맵 좌표를 사용

## 목적

- 단색 직사각형 장애물을 탑뷰 건물로 읽히게 한다.
- 건물별 색상과 옥상 장식을 달리해 맵의 반복감을 줄인다.
- 게임 판정 데이터와 건물 시각 표현을 분리한다.

## 표현 계층

아래에서 위 순서로 그린다.

1. 남동 방향으로 밀린 건물 그림자
2. 충돌 영역 바깥의 보도와 콘크리트 기단
3. 외벽
4. 안쪽으로 들어간 평평한 옥상
5. 옥상 가장자리 난간과 내부 trim
6. 환풍기, 실외기와 배관
7. 도로 방향 출입구와 차양

그림자, 보도, 설비와 차양은 모두 시각 요소이며 충돌 또는 hitscan 범위를 바꾸지
않는다. 실제 판정은 기존 `UrbanMapObstacle`의 `x`, `y`, `width`, `height`만 사용한다.

## 건물 변형

- `brick`: 따뜻한 벽돌 외벽과 갈색 차양
- `concrete`: 회색 콘크리트 외벽과 녹회색 차양
- `industrial`: 청회색 외벽과 금속 설비

각 건물은 `kind`, `style`, `entranceSide`, `fixtureVariant`만 설정한다. 장식 variant는
실외기, 환풍기와 배관 위치를 바꾸며 새로운 게임 규칙을 만들지 않는다.

형태는 세 종류를 사용한다.

- `flat`: 난간과 옥상 설비가 있는 평지붕 건물
- `house`: 중앙 용마루, 양쪽 지붕면, 굴뚝과 작은 현관이 있는 미국식 박공지붕 주택
- `storefront`: 평지붕, 도로 방향의 넓은 줄무늬 차양과 출입구가 있는 상가

주택은 지붕 남측 아래에 외벽과 창문을 노출해 탑뷰에서도 건물 높이가 읽히는 2.5D
실루엣을 사용한다. 주차선 간격은 Player 도형과 비교해 차량 한 대가 들어갈 폭으로
보이도록 유지하되, 메인 도로의 한 차로보다 좁게 구성해 실제 도로 비율을 따른다.

중앙 메인 스트리트는 노란 실선 중앙선과 양방향의 흰색 점선 차선으로 왕복 4차선을
표현한다. 중앙 교차로 내부에서는 노면 표시를 끊고, 각 진입 방향 차로 앞에는 흰색
실선 정지선을 표시한다. 한 진행 방향의 두 차로에는 `STOP` 노면 문자를 각각 하나씩
두며, 글자의 위쪽이 차량 진행 방향을 향하게 회전한다. 정지선과 문자 사이에 여백을
두고 `STOP` 뒤에서만 차선 점선을 다시 시작해 표식끼리 겹치지 않게 한다. 교차로
진입부에서는 점선 차로 구분선을 짧은 실선으로 전환하며, 정지선을 지난 뒤 교차로
경계 전까지 접근 도로 전체 폭을 가로지르는 횡단보도를 표시한다. 횡단보도의 긴 흰
막대는 `img_4`처럼 해당 도로의 차량 진행 방향과 나란히 배치한다.
횡단보도 영역에서는 기존 중앙선과 차선을 지워 노면 표시가 서로 관통하지 않게 한다.
횡단보도는 중앙 여백을 기준으로 양방향 보행 구역을 분리한다. 두 흐름의 출발점에는
줄무늬를 그리지 않아 서로 반대편에서 시작하는 엇갈린 형태를 만들고, 비워 둔 노면에
`src/assets/pedestrian-arrow.png` 화살표를 방향별로 두 개씩 배치한다. 횡단보도 영역은
중앙선과 차선을 먼저 지운 뒤 렌더링해 노면 표시가 겹치지 않게 한다.

정지선 직전의 진입 차로만 실선으로 표시하고, 교차로에서 나가는 반대 방향 차로는
일반 점선을 유지한다. 정지선과 횡단보도는 중앙 교차로에만 표시한다. 사이드
스트리트는 왕복 2차선이며 각 차로 폭은 주차면 폭 이상으로 유지한다. 보도 폭은
Player 지름 세 개 이상으로 유지해 성인 세 명이 나란히 설 수 있는 시각적 폭을
확보한다.

주차 구획선은 보도 폭과 내부 여백을 지난 주차장 포장면 안쪽에서만 시작해 보도
블록을 침범하지 않게 한다. 별도의 진입로 표시는 이 작업에서 추가하지 않는다.

모든 도로 가장자리에는 연속적인 콘크리트 보도와 밝은 연석을 표시한다. 보도와
노면 표시는 모두 시각 요소이며 이동 가능 영역이나 건물 충돌 범위를 변경하지 않는다.

평지붕과 상가도 밝은 옥상면, 북서쪽 난간 highlight, 남동쪽 난간 shadow와 남측
외벽·창문을 분리해 지면의 구멍이나 공터가 아니라 솟아 있는 건물로 읽히게 한다.

## 책임

### `urbanMapConfig.ts`

- 건물 판정 사각형
- hitscan 차단 여부
- 건물 style, 출입구 방향 및 장식 variant

### `BuildingVisual`

- 설정에 따른 도형 렌더링
- 그림자부터 옥상 설비까지 시각 계층 구성
- 게임 판정에 관여하지 않음

### `GameScene`

- 기존 장애물 설정마다 `BuildingVisual`을 한 번 생성
- 충돌 및 hitscan에는 기존 `OBSTACLE_CONFIG`를 그대로 전달

## 테스트

- 모든 건물에 시각 설정 존재
- 세 가지 건물 style이 실제 맵에서 사용됨
- 장식 variant와 출입구 방향이 허용된 값만 사용
- 기존 맵, 충돌 및 hitscan 테스트 유지

## 제외

- 정식 이미지 및 타일셋
- 실내 진입
- 열리는 문과 창문
- 파괴 가능한 건물
- 건물별 충돌 형태 변경
- 조명에 반응하는 창문
