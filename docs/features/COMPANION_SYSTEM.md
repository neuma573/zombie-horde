# Last Stand 동료 시스템

## 문서 상태와 범위

2026-09-23 사용자 요구사항을 정리한 설계 문서다. 이 작업은 문서 작성만 수행하며
동료 기능을 런타임에 구현하거나 활성화하지 않는다.

확정 요구사항, 기존 설계에서 이어지는 방향, 구현 제안과 미정 항목을 구분한다.
`LAST_STAND_MODE_COMBAT.md` 30~38절의 동료 설계 중 사기 명칭과 도주 조건은
이 문서의 최신 요구사항을 우선한다. 나머지 전투 설계를 이번 요청으로 모두 확정한 것은 아니다.

## 1. 확정 요구사항: 동료 생성

- 동료는 낮 탐색 중 발견되어 합류할 수 있다.
- 발견한 동료는 자동 합류하며, 당일 밤부터 참전할 수 있다. 참전에는 별도의 인원 선택과 탄약 비용 조건이 적용된다.
- 최대 동료 수는 플레이어를 제외한 4명이다.
- 생성 시 성별은 남성 또는 여성 중 무작위로 결정한다.
- 성별에 맞는 이름 후보를 사용해 성과 이름을 무작위로 조합한다.
- 동료마다 초기 사기 `courage`를 무작위로 부여한다.
- 플레이어에게는 동료용 `courage` 수치를 부여하지 않는다.

성별 확률, 이름 목록과 문화권, 성 후보의 성별 공유 여부, 동명이인 허용 여부,
초기 `courage`의 범위와 분포는 아직 정하지 않았다. 성별에 따른 능력 차이도
요청되지 않았으므로 이름·성별 생성 규칙에서 추론하지 않는다.

## 2. 확정 요구사항: 낮 일과와 인원 배분

- 동료를 탐색 또는 바리케이드 수리에 활용할 수 있다.
- 탐색·수리에 참여할 동료를 이름별로 직접 선택한다.
- 플레이어와 동료는 각자 하루 12시간을 가지며, 탐색과 수리를 서로 다른 인원이 동시에 수행할 수 있다.
- 같은 탐색에 인원이 늘면 소요 시간이 줄고 위험이 감소한다. 인원 증가 자체로 보상은 증가하지 않는다.
- 탐색에 투입한 동료를 잃을 수 있다. 손실은 **실종**과 **사망**으로 구분하지만 현재는 모든 손실을 사망으로 구현한다.
- 사기가 낮은 동료는 탐색 효율이 떨어지고 좋지 않은 결과를 야기할 수 있다.
- 사기가 낮을수록 탐색 중 사망 위험이 높아진다.

인원별 시간 단축·위험 감소 공식과 사기에 따른 효율 계산은 미정이다.
플레이어는 탐색 중 절대 사망하지 않는다.

## 3. 확정 요구사항: 손실과 사기

- 동료가 사망하면 전원의 사기가 떨어진다. 사기를 가진 대상은 플레이어를 제외한 동료다.
- 사망에 따른 영향은 해당 탐색에 참여한 동료만으로 한정하지 않는다.
- 현재 구현에서는 탐색 손실을 모두 사망으로 처리한다. 실종은 향후 확장 개념이며 현재 결과로 발생시키지 않는다.
- 휴식 시간이 주어지면 사기가 회복된다.
- 매일 밤 생존에 성공하면 도주자를 제외한 동료 전원의 사기가 조금씩 오른다. 야간전에 참여하지 않은 동료도 포함한다.

사망 한 명당 감소량, 같은 탐색의 여러 사망 처리 순서, 휴식 시간당 회복량,
야간 생존 보너스의 정확한 회복량은 미정이다. 도주자는 다음 절의 아침 최저 사기 복귀
규칙을 만족해야 하므로, 생존 보너스로 복귀 시 사기가 최저치보다 높아져서는 안 된다.

## 4. 확정 요구사항: 야간 도주

사기가 낮으면 야간 전투에서 더 일찍 도망칠 수 있다. 바리케이드가 아직 건재해도
도주할 수 있으며, 사기 수준에 따라 버티는 정도가 달라진다.

| 동료 상태 | 확정된 도주 조건 또는 경향 |
| --- | --- |
| 사기가 낮은 동료 | 더 일찍 도주할 수 있으며 바리케이드가 건재해도 도주 가능 |
| 기본 수준의 사기를 가진 동료 | 바리케이드 내구도가 **10% 미만**이면 도주 |
| 최고 수준의 사기를 가진 동료 | 바리케이드 내구도가 **0%**가 되면 도주 |

정확히 10%인 상태는 ‘10% 미만’ 조건에 포함하지 않는다. 다만 사기에 따른 별도
도주 조건이 충족되는지는 구체적인 공식이 정해진 후 판단한다.

‘더 빠르게 도망간다’는 도주 시점이 앞당겨진다는 요구로 정리한다.
최고 수준의 `courage`를 가진 동료도 내구도 0%에서는 도주한다.

야간 도주는 탐색 중 사망과 구분한다. 도주한 동료는 아침에 사기가 최저치인 상태로
복귀한다. 영구 이탈이나 사망으로 처리하지 않는다.

야간 패배 후 재도전은 **낮 결과를 유지한 야간 준비 화면**으로 돌아간다.
낮 탐색의 보상·합류·사망과 수리·휴식 결과를 다시 정산하거나 추첨하지 않는다.
명단·사기·자원·무기·바리케이드는 야간 시작 전 상태로 복원하며, 실패한 밤의
도주·피해·탄약 소비는 누적하지 않는다. 재도전 준비 화면에서 무장과 참전 인원을
다시 선택할 수 있도록 하고, 다시 출전할 때 선택한 동료 수에 맞춰 탄약을 차감한다.

## 5. 기존 야간 설계와의 관계

기존 설계에는 동료의 자동 사격과 `ACTIVE → FLEEING → LEFT_COMBAT` 상태 전이가
있다. 도주 상태를 판정한 뒤 이동 연출을 거쳐 전투에서 이탈하는 방향은 참고할 수 있다.

확정된 무장·참전 규칙은 다음과 같다.

- 동료의 기본 무기는 플레이어의 기본 권총보다 연사력이 현저히 낮고, 한 발의 피해량도 조금 낮은 권총이다.
- 기본 권총의 전투 기여도는 매우 작아야 한다. 사용자가 표현한 ‘없으니만 못한 정도’의 약한 무장을 밸런스 목표로 삼는다. 이 표현만으로 아군 피해 등 별도 불이익 규칙을 추가하지 않는다.
- 플레이어가 동료의 무기를 배정하고, 각 동료의 야간전 참여 여부를 결정한다.
- 보유 무기 한 자루는 플레이어 또는 동료 한 명에게만 배정할 수 있다. 같은 자루를 여러 사람에게 중복 배정할 수 없다. 예를 들어 샷건 한 자루를 동료에게 배정하면 플레이어와 다른 동료는 그 샷건을 동시에 사용할 수 없다.
- 야간 시작 시 참전 동료 1명당 탄약 자원 `Ammo` 1을 차감한다. 플레이어는 이 비용에서 제외한다.
- 탄약이 부족하면 그 비용을 충당할 수 없는 동료는 참전할 수 없다. 보유 탄약으로 감당할 수 있는 인원 안에서 직접 선택한다.
- 동료도 전투 중 예비 탄약은 무제한이다. 탄창과 재장전은 무기 설정대로 적용한다.

참전 비용인 자원 `Ammo`와 전투 중 탄창·예비 탄약은 구분한다.
동료용 기본 권총의 정확한 발사 간격·피해량 등 세부 수치, 무기의 획득·보유 수량
관리와 기본 권총 지급 방식, 조준·사격 성능과 도주 경로는 아직 정하지 않았다.

Hazard는 단일 방어선이다. 향후 다중 방어선에서는 기존 문서의 ‘배치된 구역의
바리케이드 기준’ 방향을 참고하되, 전 구역 연쇄 도주 규칙을 임의로 추가하지 않는다.

기존의 `morale`은 새 동료 시스템에서 `courage`로 통일한다. 기존 문서의
‘모든 동료가 10% 미만에서 일괄 도주’ 조건은 최신 요구사항을 충분히 표현하지 못한다.
기본 사기의 10% 미만 도주와 최고 사기 동료의 0% 도주를 구분해야 한다.

## 6. 관련 확정 요구사항: 붕괴 후 좀비 접근

바리케이드가 깨지면 좀비가 플레이어에게 조금 느리게 접근해야 한다.
의도하는 분위기는 맹수가 사냥감을 천천히 압박하는 느낌이다.

이 행동은 동료의 상태 관리와 별개로 구현할 전투 변경이다.

- 붕괴 후에는 일반·빠른 좀비의 기존 속도 차이를 적용하지 않고 동일한 느린 속도로 접근한다.
- 좀비 접촉에 따른 패배 시 플레이어가 납작해지는 연출을 암전으로 대체한다.

정확한 접근 속도, 감속 적용 시점·지속 시간, 암전 시간은 미정이다.
별도 요구가 없는 Horde 모드까지 변경을 확대하지 않는 구현 범위를 제안한다.

## 8. 구현 구조 제안

다음은 책임 분리 제안이며 이름과 API는 구현 단계에서 결정한다.

- **설정**: 이름 후보, 성별 확률, 초기 사기 분포, 합류·사망 확률, 사기 영향 계수.
- **동료 상태**: 표시 이름과 별개의 고유 ID, 성별, 성·이름, `courage`, 합류·손실 상태.
- **순수 판정**: 동료 생성, 사기 변화, 탐색 위험·효율, 도주 조건을 Phaser 없이 계산.
- **동료 시스템**: 명단과 상태 전이를 소유하고 사망에 따른 사기 감소를 한 번만 적용.
- **일과 조정**: 참여자와 배분을 검증한 뒤 결과를 한 번만 정산. UI가 직접 명단을 변경하지 않음.
- **전투 연결**: 영구 명단 상태와 야간 임시 전투 상태를 구분하고 낮·밤 전환 시 결과를 전달.
- **표현**: 결과 기록, 명단과 사기 표시, 도주 연출을 게임 판정과 분리.

난수는 주입 가능한 공급원으로 전달해 같은 초기 상태·입력·난수열에서 같은 결과가
나오도록 한다. 화면 재표시·리사이즈로 성별·이름·사기나 탐색 결과를 다시 추첨하지 않는다.

## 10. 단계별 작업 제안과 검증

한 작업에서 여러 기능을 동시에 구현하지 않는 프로젝트 규칙에 따라 아래처럼
나누는 방안을 제안한다. 이 순서와 각 단계의 범위는 아직 구현 승인으로 간주하지 않는다.

1. 동료 생성·명단·`courage`와 탐색 합류·사망.
2. 일과 인원 배분과 사기에 따른 탐색 효율·위험.
3. 야간 무장·참전과 동료 행동·사기별 도주·아침 복귀·재도전 복원. 세부 작업은 구현 전에 나눈다.
4. 바리케이드 붕괴 후 좀비 접근 감속.
5. 접촉 패배 연출을 암전으로 교체.

테스트는 `docs/TESTING.md`를 따른다. 구현 시 필요한 주요 검증은 다음과 같다.

- **Unit**: 결정적 성별·이름·사기 생성, 사기 하한·상한, 효율·위험 함수, 10% 직전·정확히 10%·직후와 0% 도주 경계.
- **Contract**: 동료 기본 권총이 주인공 기본 권총보다 훨씬 느리게 사격하고 한 발 피해량도 낮다는 밸런스 의도.
- **System**: 명단 중복 처리 방지, 탐색 손실의 사망 처리, 사망 사건별 사기 감소 1회 적용, 개인별 시간 예산과 배분 검증, 참전 탄약 정산.
- **System**: 최대 동료 4명 제한, 자동 합류와 당일 밤 참전 가능 여부.
- **System**: 플레이어와 동료 전체에서 무기 한 자루의 중복 배정 거부, 배정 해제 후 다른 인원에게 재배정 가능 여부.
- **Scenario**: 탐색 합류 → 일과 배분 → 사망·휴식에 따른 사기 변화 → 야간 참전·도주 → 아침 최저 사기 복귀. 비참전 동료의 생존 회복, 낮 결과를 유지하는 재도전, 실패한 밤의 탄약 차감 복원도 검증.
- **시간 검증**: 야간 판정·도주 이동·좀비 감속이 프레임 분할에 영향을 받지 않는지 확인.
- **Browser**: PC·모바일 명단 및 배분 UI, 낮·밤 전환, 도주 연출과 리사이즈.

확정되지 않은 확률과 계산식은 임의의 테스트 계약으로 고정하지 않는다.
