# Last Stand 동료 시스템

## 문서 상태와 범위

2026-09-23 사용자 요구사항과 구현 내용을 정리한 문서다. 문서 확정 후 동료 명단,
낮 배분, 야간 참전·도주, 재도전 복원, 붕괴 후 감속과 패배 암전을 순차 구현했다.
2026-09-28 요청에 따라 낮 일과는 공용 12시간을 쓰는 하나의 탐색팀으로 단순화했다.
사용자가 지정하지 않은 수치와 세부 규칙은 11절의 조정 가능한 초기 구현값을 사용한다.

확정 요구사항, 기존 설계에서 이어지는 방향, 구현 제안과 미정 항목을 구분한다.
`LAST_STAND_MODE_COMBAT.md` 30~38절의 동료 설계 중 사기 명칭과 도주 조건은
이 문서의 최신 요구사항을 우선한다. 나머지 전투 설계를 이번 요청으로 모두 확정한 것은 아니다.

## 1. 확정 요구사항: 동료 생성

- 동료는 낮 탐색 중 발견되어 합류할 수 있다.
- 발견한 동료는 자동 합류하며, 당일 밤부터 참전할 수 있다. 참전에는 별도의 인원 선택과 탄약 비용 조건이 적용된다.
- 낮 탐색·수리 배정은 합류 다음 날부터 가능하다. 탐색 결과 뒤에는 작업 배분 창을 자동으로 열지 않는다.
- 최대 동료 수는 플레이어를 제외한 4명이다.
- 생성 시 성별은 남성 또는 여성 중 무작위로 결정한다.
- 성별에 맞는 이름 후보를 사용해 성과 이름을 무작위로 조합한다.
- 동료마다 초기 사기 `courage`를 무작위로 부여한다.
- 플레이어에게는 동료용 `courage` 수치를 부여하지 않는다.

성별 확률, 이름 목록과 문화권, 성 후보의 성별 공유 여부, 동명이인 허용 여부,
초기 `courage`의 범위와 분포는 아직 정하지 않았다. 성별에 따른 능력 차이도
요청되지 않았으므로 이름·성별 생성 규칙에서 추론하지 않는다.

## 2. 확정 요구사항: 낮 일과와 인원 배분

- 동료를 탐색 또는 바리케이드 수리에 활용할 수 있다.
- 플레이어와 참여 가능한 생존 동료 전원이 자동으로 탐색에 동행한다. 탐색 인원 선택과 개인별 수리 조작은 제공하지 않는다.
- 지도에서 건물을 클릭하면 메모에 탐색 시간과 동행자 이름을 표시한다. 체크박스나 별도 동료 메뉴를 두지 않는다.
- 플레이어가 모든 탐색에 필수 참여하며, 합류 당일 동료와 사망한 동료는 자동 동행에서 제외한다. 동료만 별도 팀으로 보내지 않는다.
- 하루 12시간을 공유하며, 선택한 건물을 순서대로 탐색한 뒤 함께 수리한다. 탐색과 수리 뒤 남은 시간은 휴식한다.
- 하단에서 공용 수리 시간을 한 번 설정하면 플레이어와 참여 가능한 동료가 함께 돕는다. 내구도 100% 회복에 필요한 인원·시간까지만 사용한다. 수리 시간은 탐색 후 남은 공용 시간 안에서만 정할 수 있으며, 탐색과 수리를 병렬 배정하지 않는다.
- 같은 탐색에 인원이 늘면 소요 시간이 줄고 위험이 감소한다. 인원 증가 자체로 보상은 증가하지 않는다.
- 탐색에 투입한 동료를 잃을 수 있다. 손실은 **실종**과 **사망**으로 구분하지만 현재는 모든 손실을 사망으로 구현한다.
- 사기가 낮은 동료는 탐색 효율이 떨어지고 좋지 않은 결과를 야기할 수 있다.
- 사기가 낮을수록 탐색 중 사망 위험이 높아진다.

인원별 시간 단축·위험 감소 공식과 사기에 따른 효율 계산은 미정이다.
플레이어는 탐색 중 절대 사망하지 않는다.

## 3. 확정 요구사항: 손실과 사기

- 동료가 사망하면 전원의 사기가 떨어진다. 사기를 가진 대상은 플레이어를 제외한 동료다.
- 사망에 따른 영향은 해당 탐색에 참여한 동료만으로 한정하지 않는다.
- 현재 구현에서는 탐색 손실을 모두 사망으로 처리한다. 실종은 향후 확장 개념이며 현재 결과로 발생시키지 않는다.
- 휴식 시간이 주어지면 사기가 회복된다.
- 매일 밤 생존에 성공하면 도주자를 제외한 동료 전원의 사기가 조금씩 오른다. 야간전에 참여하지 않은 동료도 포함한다.

사망 한 명당 감소량, 같은 탐색의 여러 사망 처리 순서, 휴식 시간당 회복량,
야간 생존 보너스의 정확한 회복량은 미정이다. 도주자는 다음 절의 아침 최저 사기 복귀
규칙을 만족해야 하므로, 생존 보너스로 복귀 시 사기가 최저치보다 높아져서는 안 된다.

## 4. 확정 요구사항: 야간 도주

사기가 낮으면 야간 전투에서 더 일찍 도망칠 수 있다. 바리케이드가 아직 건재해도
도주할 수 있으며, 사기 수준에 따라 버티는 정도가 달라진다.

| 동료 상태 | 확정된 도주 조건 또는 경향 |
| --- | --- |
| 사기가 낮은 동료 | 더 일찍 도주할 수 있으며 바리케이드가 건재해도 도주 가능 |
| 기본 수준의 사기를 가진 동료 | 바리케이드 내구도가 **10% 미만**이면 도주 |
| 최고 수준의 사기를 가진 동료 | 바리케이드 내구도가 **0%**가 되면 도주 |

정확히 10%인 상태는 ‘10% 미만’ 조건에 포함하지 않는다. 다만 사기에 따른 별도
도주 조건이 충족되는지는 구체적인 공식이 정해진 후 판단한다.

사기에 따른 조기 도주와 별개로, 도주를 시작하면 빠르게 달려서 퇴장한다.
최고 수준의 `courage`를 가진 동료도 내구도 0%에서는 도주한다.

야간 도주는 탐색 중 사망과 구분한다. 도주한 동료는 아침에 사기가 최저치인 상태로
복귀한다. 영구 이탈이나 사망으로 처리하지 않는다.

야간 패배 후 재도전은 **낮 결과를 유지한 야간 준비 화면**으로 돌아간다.
낮 탐색의 보상·합류·사망과 수리·휴식 결과를 다시 정산하거나 추첨하지 않는다.
명단·사기·자원·무기·바리케이드는 야간 시작 전 상태로 복원하며, 실패한 밤의
도주·피해·탄약 소비는 누적하지 않는다. 재도전 준비 화면에서 무장과 참전 인원을
다시 선택할 수 있도록 하고, 다시 출전할 때 선택한 동료 수에 맞춰 탄약을 차감한다.

## 5. 기존 야간 설계와의 관계

기존 설계에는 동료의 자동 사격과 `ACTIVE → FLEEING → LEFT_COMBAT` 상태 전이가
있다. 도주 상태를 판정한 뒤 이동 연출을 거쳐 전투에서 이탈하는 방향은 참고할 수 있다.

확정된 무장·참전 규칙은 다음과 같다.

- 동료의 기본 무기는 플레이어의 기본 권총보다 연사력이 현저히 낮고, 한 발의 피해량도 조금 낮은 권총이다.
- 기본 권총의 전투 기여도는 매우 작아야 한다. 사용자가 표현한 ‘없으니만 못한 정도’의 약한 무장을 밸런스 목표로 삼는다. 이 표현만으로 아군 피해 등 별도 불이익 규칙을 추가하지 않는다.
- 플레이어가 동료의 무기를 배정하고, 각 동료의 야간전 참여 여부를 결정한다.
- 보유 무기 한 자루는 플레이어 또는 동료 한 명에게만 배정할 수 있다. 같은 자루를 여러 사람에게 중복 배정할 수 없다. 예를 들어 샷건 한 자루를 동료에게 배정하면 플레이어와 다른 동료는 그 샷건을 동시에 사용할 수 없다.
- 야간 시작 시 참전 동료 1명당 탄약 자원 `Ammo` 1을 차감한다. 플레이어는 이 비용에서 제외한다.
- 탄약이 부족하면 그 비용을 충당할 수 없는 동료는 참전할 수 없다. 보유 탄약으로 감당할 수 있는 인원 안에서 직접 선택한다.
- 동료도 전투 중 예비 탄약은 무제한이다. 탄창과 재장전은 무기 설정대로 적용한다.

참전 비용인 자원 `Ammo`와 전투 중 탄창·예비 탄약은 구분한다.
동료용 기본 권총의 정확한 발사 간격·피해량 등 세부 수치, 무기의 획득·보유 수량
관리와 기본 권총 지급 방식, 조준·사격 성능과 도주 경로는 아직 정하지 않았다.

Hazard는 단일 방어선이다. 향후 다중 방어선에서는 기존 문서의 ‘배치된 구역의
바리케이드 기준’ 방향을 참고하되, 전 구역 연쇄 도주 규칙을 임의로 추가하지 않는다.

기존의 `morale`은 새 동료 시스템에서 `courage`로 통일한다. 기존 문서의
‘모든 동료가 10% 미만에서 일괄 도주’ 조건은 최신 요구사항을 충분히 표현하지 못한다.
기본 사기의 10% 미만 도주와 최고 사기 동료의 0% 도주를 구분해야 한다.

## 6. 관련 확정 요구사항: 붕괴 후 좀비 접근

바리케이드가 깨지면 좀비가 플레이어에게 조금 느리게 접근해야 한다.
의도하는 분위기는 맹수가 사냥감을 천천히 압박하는 느낌이다.

이 행동은 동료의 상태 관리와 별개로 구현할 전투 변경이다.

- 붕괴 후에는 일반·빠른 좀비의 기존 속도 차이를 적용하지 않고 동일한 느린 속도로 접근한다.
- 좀비 접촉에 따른 패배 시 플레이어가 납작해지는 연출을 암전으로 대체한다.

정확한 접근 속도, 감속 적용 시점·지속 시간, 암전 시간은 미정이다.
별도 요구가 없는 Horde 모드까지 변경을 확대하지 않는 구현 범위를 제안한다.

## 8. 책임 분리 원칙

구현은 다음 책임 분리를 따른다.

- **설정**: 이름 후보, 성별 확률, 초기 사기 분포, 합류·사망 확률, 사기 영향 계수.
- **동료 상태**: 표시 이름과 별개의 고유 ID, 성별, 성·이름, `courage`, 합류·손실 상태.
- **순수 판정**: 동료 생성, 사기 변화, 탐색 위험·효율, 도주 조건을 Phaser 없이 계산.
- **동료 시스템**: 명단과 상태 전이를 소유하고 사망에 따른 사기 감소를 한 번만 적용.
- **일과 조정**: 참여자와 배분을 검증한 뒤 결과를 한 번만 정산. UI가 직접 명단을 변경하지 않음.
- **전투 연결**: 영구 명단 상태와 야간 임시 전투 상태를 구분하고 낮·밤 전환 시 결과를 전달.
- **표현**: 결과 기록, 명단과 사기 표시, 도주 연출을 게임 판정과 분리.

난수는 주입 가능한 공급원으로 전달해 같은 초기 상태·입력·난수열에서 같은 결과가
나오도록 한다. 화면 재표시·리사이즈로 성별·이름·사기나 탐색 결과를 다시 추첨하지 않는다.

## 9. 추가 조정 가능한 항목

| 항목 | 사용자 지정값이 없는 세부 정책 |
| --- | --- |
| 생성 | 성별 확률, 이름 후보, 중복 이름, 초기 사기 범위·분포 |
| 합류 | 발견 확률, 정원 4명에 도달했을 때 발견 처리, 발견 당일의 낮 일과 참여 가능 여부 |
| 인원 배분 | 동행 인원별 시간 단축·위험 감소 공식 |
| 탐색 결과 | 사기별 효율, 나쁜 결과의 종류, 사망 확률, 한 번에 여러 명 사망 가능 여부 |
| 사기 변화 | 사망 감소량·하한·상한, 휴식 회복량, 야간 생존 보너스 회복량, 사건 처리 순서 |
| 도주 | 기본 사기 값, 건재한 바리케이드에서의 판정, 중간 사기 구간 임계값, 이동 경로 |
| 재도전 | 낮 결과는 유지하고 야간 준비 상태로 복원하되, 밤의 좀비 생성 등 난수열도 반복할지는 미정 |
| 무장·참전 | 동료용 권총의 정확한 수치, 무기의 획득·보유 수량 관리와 기본 권총 지급 방식 |
| 붕괴 후 접근·패배 연출 | 공통 접근 속도·적용 시점·지속 시간, 암전 시간 |

## 10. 단계별 작업 제안과 검증

한 작업에서 여러 기능을 동시에 구현하지 않는 프로젝트 규칙에 따라 아래 순서로
개별 변경을 구현하고 각 단계에서 전체 테스트와 빌드를 검증했다.

1. 동료 생성·명단·`courage`와 탐색 합류·사망.
2. 일과 인원 배분과 사기에 따른 탐색 효율·위험.
3. 야간 무장·참전과 동료 행동·사기별 도주·아침 복귀·재도전 복원. 세부 작업은 구현 전에 나눈다.
4. 바리케이드 붕괴 후 좀비 접근 감속.
5. 접촉 패배 연출을 암전으로 교체.

테스트는 `docs/TESTING.md`를 따른다. 구현 시 필요한 주요 검증은 다음과 같다.

- **Unit**: 결정적 성별·이름·사기 생성, 사기 하한·상한, 효율·위험 함수, 10% 직전·정확히 10%·직후와 0% 도주 경계.
- **Contract**: 동료 기본 권총이 주인공 기본 권총보다 훨씬 느리게 사격하고 한 발 피해량도 낮다는 밸런스 의도.
- **System**: 명단 중복 처리 방지, 탐색 손실의 사망 처리, 사망 사건별 사기 감소 1회 적용, 공용 시간 예산·전원 자동 동행·순차 탐색 검증, 참전 탄약 정산.
- **System**: 최대 동료 4명 제한, 자동 합류와 당일 밤 참전 가능 여부.
- **System**: 플레이어와 동료 전체에서 무기 한 자루의 중복 배정 거부, 배정 해제 후 다른 인원에게 재배정 가능 여부.
- **Scenario**: 탐색 합류 → 일과 배분 → 사망·휴식에 따른 사기 변화 → 야간 참전·도주 → 아침 최저 사기 복귀. 비참전 동료의 생존 회복, 낮 결과를 유지하는 재도전, 실패한 밤의 탄약 차감 복원도 검증.
- **시간 검증**: 야간 판정·도주 이동·좀비 감속이 프레임 분할에 영향을 받지 않는지 확인.
- **Browser**: PC·모바일 명단 및 배분 UI, 낮·밤 전환, 도주 연출과 리사이즈.

사용자 확정 요구와 초기 밸런스 가정을 구분하며, 밸런스 테스트는 핵심 상대 관계를 검증한다.


## 11. 초기 구현값과 세부 정책

다음은 사용자가 직접 지정한 고정 수치가 아닌 **조정 가능한 초기 구현값**이다.
설정은 `companionConfig.ts`와 `lastStandCombatConfig.ts`에서 관리한다.

| 항목 | 초기 구현 |

| 생성 | 남녀 각 50%, 영어권 이름·성 조합, 초기 사기 35~85 정수 균등 분포 |
| 이름 중복 | 생존 동료의 이름이 겹치면 성 후보를 바꿔 직접 선택 시 구분 가능하게 함 |

| 교전 거리 | 무기 사거리와 700 월드 단위 중 작은 값으로 탐지·명중 판정을 제한. 실내 영역에 들어온 적만 표적으로 선택해 보이지 않는 실외 생성 구역의 적을 미리 겨냥하지 않음 |
| 조준 | 발사마다 기본 ±10° 오차 적용. 무기 자체 기본 퍼짐이 더 크면 그 값을 사용. 동료별 결정적 난수열로 서로 다른 오차를 적용하며 산탄은 이 방향에 추가 분산 |
| 반응·표적 변경 | 새 표적을 발견하면 650~1,150ms 조준. 초당 최대 180°로 방향을 돌리며, 더 가까운 적이 나타나도 현재 표적이 유효하면 유지 |

| 자리 이동 | 3.5~6.5초 간격으로 휴지기·재장전·대기 중 짧게 이동. 배치 위치의 반경 24 안에서 초당 32 속도로 움직이며 방어 구역·장애물·다른 동료를 고려. 이동 중 새 사격을 시작하지 않고 정지 후 최소 250ms 조준 |
| 총구 효과 | 동료 모델의 실제 총구에서 표시하고 발사자 ID별로 추적. 플레이어 총구 갱신은 동료 효과를 이동시키지 않음 |
| 공용 무기 | 현재 무기 종류당 한 자루. 경찰서에서 점사 소총, 주택 B에서 샷건을 회수하는 초기 배치 |
| 참전 | 동료 1명당 Ammo 1 선차감, 예비 탄약 무제한, 탄창·재장전 적용 |
| 도주 | 사기 0은 즉시 도주. 0~50 구간의 내구도 임계값은 100%~10%, 50~100 구간은 10%~0%로 선형 변화. 임계값 미만에서 도주하며 내구도 0은 예외 없이 도주 |
| 도주 연출 | 전투 중에는 플레이어와 같은 불투명 남녀 모델을 사용. 도주 속도는 초당 260 월드 단위. Hazard에서는 실내 통로를 거쳐 동쪽 후문으로 나가며 벽·가구 충돌을 적용. 퇴장 지점까지 남은 거리가 80 이하일 때만 점차 사라짐. 도주 시작 후 다시 참전하지 않음 |
| 붕괴 후 접근 | 소속 바리케이드가 0이 된 직후부터 일반·빠른 좀비 모두 초당 38 월드 단위. 플레이어까지의 경로가 뚫린 구역을 지나면 중앙에 모이지 않고 바로 추적. 군집 간격 보정도 감속 비율에 맞춰 줄여 전진이 상쇄되지 않게 함. Horde는 기존 속도 유지 |
| 패배 | 650ms 암전 후 확인 버튼. 낮 결과는 유지하고 야간 시작 전 탄약·명단·사기·바리케이드로 재도전 |

낮 일과는 플레이어와 참여 가능한 동료 전원으로 구성한 하나의 팀으로 처리한다.
모든 탐색은 선택 순서대로 진행하며, 탐색 시간 합계와 공용 수리 시간이 하루
12시간을 넘으면 배정을 거부한다. 이미 직접 탐색에 사용한 시간도 같은 예산에 포함한다.
개인별 일정·대기 시간·별도 팀의 병렬 탐색은 제공하지 않는다.
시간 부족 안내는 하루 전체 필요 시간/12시간을 표시한다. 건물 메모에는 플레이어의
이름과 탐색 시간을 표시하며, 동행 선택이나 개인별 잔여 시간을 표시하지 않는다.
탐색과 수리에 사용하지 않은 시간은 해당 동료의 휴식으로 정산한다.

실제 정산에서는 매 탐색 시작 전 생존 인원과 사기로 소요 시간을 다시 계산한다.
사망한 동료는 이후 장소를 탐색하거나 수리하지 못한다. 플레이어는 탐색 중 사망하지
않으므로 물자·무기는 플레이어가 회수한다. 시간 초과로 방문하지 못한 이후 장소는
미탐색으로 남긴다. 새 탐색을 자동 추가하지 않으며, 수리는 설정한 시간과 실제 남은
공용 시간 안에서 생존 인원에게 다시 배분한다. 생존자와 신규
합류 결과는 한 번만 확정하고 재도전·화면 재표시로 다시 추첨하지 않는다.

낮 판정과 명단은 탐색 시스템이 소유하고, 야간 전투에는 복사본을 전달한다.
패배한 밤의 피해·도주는 영구 상태를 변경하지 않는다. 참전 비용은 복원 후 재출전할
때 다시 한 번 차감한다. 승리 결과 중복 전달로 날짜·사기가 반복 증가하지 않는다.
밤의 적 생성 난수열은 재도전 시 새로 진행한다.

탐색 결과는 기존 결과지에 합류·사망·획득 무기를 함께 표시한다. 합류와 무기 획득은
각각 ‘동료 합류’, ‘무기 확보’ 대제목 아래 이름만 표시한다.

건물 메모에는 플레이어와 참여 가능한 동료의 이름만 표시한다. 합류 당일의 동료는
제외하며, 다음 날부터 모든 탐색에 자동 동행한다. 건물을 해제하거나 다시 추가해도
인원 선택 상태는 존재하지 않는다. 메모를 보는 것만으로 시간을 사용하지 않으며,
건물을 계획에 추가할 때 탐색 시간을 배정한다. 공용 12시간을 넘는 추가는 기존 계획을
유지한 채 거부한다. 좁은 화면에서는 건물 클릭 시 메모 페이지를 연다.
완료한 장소의 동행자와 소요 시간은 보존하고, 사망한 동료는 이후 탐색에서 제외한다.
즉시 탐색 경로에도 같은 자동 동행·효율·위험 규칙을 적용한다.

수리 조절부에는 공용 수리 시간, 플레이어를 포함한 현재 작업 가능 인원과
‘1인당 시간당 5포인트 회복’만 안내한다. 자동 수리 안내, 인원별 예상 회복량과
수색 장소 수·남은 휴식 시간의 별도 요약은 표시하지 않는다.
상단 시간표는 하나의 하루 계획으로 탐색·수리·휴식 시간을 표시한다. 별도 계획 확인
팝업 없이 ‘탐색 시작’으로 바로 정산하며, 수색 장소가 없으면 ‘하루 보내기’를 표시한다.
탐색 완료 화면의 ‘다음’ 버튼으로 무기고에 진입한다.
결과 정산 뒤의 수리 인원·시간·회복량은 실제 완료한 작업을 표시한다.

무기고는 기존 나무 진열장을 유지하고, 상단 카드로 플레이어·동료 전원을 표시한다.
카드에는 이름, 무기 그림과 출전 체크박스를 표시하며, 좁은 화면에서는 두 줄로 배치한다.
넓고 충분히 높은 화면에서는 동료 목록을 왼쪽 세로 열에, 무기를 오른쪽 2열 진열대에
배치한다. 하단은 장착 슬롯과 우측 시작 버튼으로 나누며, PC 무기고 높이는 최대 680으로
제한해 빈 진열 공간을 줄인다. 체크박스의 넓은 클릭 영역에는 배경을 그리지 않는다.
출전 여부는 카드의 체크박스로 바로 변경한다. 동료 카드를 선택한 뒤 진열대 무기를 누르면
즉시 지급하며, 지급된 무기 슬롯을 누르면 개인용 낡은 권총으로 되돌린다.
플레이어는 기존대로 진열대 무기 선택 후 두 슬롯 중 하나를 눌러 장착한다.
긴 조작 안내와 반복되는 무기명·상태 문구를 제거하고, 선택한 동료의 사기는 한 번만 표시한다.
시작 버튼 위에는 참전 동료 수와 탄약 비용을 표시한다. 참전은 자동 선택하지 않는다.
개발 서버에서는 메인 메뉴에서 F8을 누르면 동료 4명, 추가 무기 3종, 탄약 3이
준비된 2일차 무기고로 임시 진입한다. 출전 인원 선택, 무기 지급과 탄약 부족을 확인할 수
있으며, 실제 진행 중인 게임을 건너뛰는 용도는 아니다. 배포 빌드에서는 F8 진입을 활성화하지 않는다.
결과지에서 무기고로, 무기고에서 전투로 이동할 때 각각 350ms 검은 페이드 아웃·인을
적용한다. 전환 중 입력을 막으며, 전투의 시간·적 갱신은 페이드 인이 끝난 뒤 시작한다.
밤 종료 후 지도나 무기고로 돌아올 때도 페이드 인으로 화면을 복원한다.

### 검증과 알려진 범위

- 기존 테스트를 삭제하거나 완화하지 않고 동료 규칙·명단·시간 배분·무기 배정·전투·재도전 시나리오를 추가했다.
- Chrome에서 데스크톱, 모바일 세로·가로 크기의 UI와 실제 배정 클릭, 야간 진입, 접촉 패배 암전, 재도전 탄약 복원을 확인했다.
- 이후 조준·사격 휴지기·자리 이동·교전 거리·도주 속도 조정은 순수 로직과 시스템 테스트로 검증했다. 이 조정의 브라우저 플레이 확인은 사용자 요청에 따라 사용자가 진행한다.
- 실제 휴대전화 검증과 장시간 밸런스 플레이는 별도로 필요하다.
- 기존 빌드의 500KB 초과 번들 경고는 유지된다.
- 동료의 별도 체력·야간 사망, 다중 방어선 배치 UI, 저장 기능은 이번 구현에 포함하지 않는다.
