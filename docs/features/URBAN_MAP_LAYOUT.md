# 고정형 도심 맵 레이아웃

## 상태

- 현재 구현 기준 문서
- 중간 규모 고정 맵 한 개
- 랜덤 맵 생성과 복잡한 길 찾기는 포함하지 않음

## 목적

- 단일 직사각형 장애물만 있던 전장을 작은 도심 교차로 형태로 개선한다.
- 플레이어가 엄폐, 우회 및 교차로 방어를 선택할 수 있게 한다.
- 기존 충돌, hitscan 차단 및 반응형 카메라 경계를 그대로 사용한다.
- 현재의 직접 추적 Zombie가 완전히 고립되지 않도록 넓은 순환 동선을 보장한다.

## 레이아웃

- 맵 크기: 2,400 × 1,600
- 플레이어 시작 위치: 중앙 교차로 `(1,200, 800)`
- 가로·세로 간선도로 폭: 320
- 중앙 교차부는 정사각형 비율로 유지
- 중앙 차선은 교차부에 진입하기 전에 끊어서 도로 방향선이 교차하지 않게 표시
- 중앙 교차로 바깥에 폭 160의 순환도로를 배치한다.
- 중앙도로와 순환도로를 세 개의 연결도로로 이어 복수의 순환 경로를 만든다.
- 크기와 위치가 다른 직사각형 건물 6개를 비대칭으로 배치한다.
- 남서 구역은 장애물이 없는 주차장으로 두어 넓은 전투·도주 공간을 제공한다.
- 맵 외곽과 건물 사이에는 edge spawn을 위한 빈 공간을 유지한다.

도로, 차선과 주차선은 시각 레이어이며 충돌 판정에 관여하지 않는다. 건물 블록만 기존
`OBSTACLE_CONFIG`로 노출되어 Player와 Zombie 이동을 막고 hitscan을 차단한다.

## 책임

### `urbanMapConfig.ts`

- 고정 맵 크기와 grid 간격
- 도로 영역
- 주차장 영역
- 건물 장애물과 hitscan 차단 속성

### `WorldBackdrop`

- 기본 지면, 도로, 차선 및 주차선 표시
- resize 시 현재 월드 크기로 다시 그리기
- 게임 판정에는 관여하지 않음

### `Obstacle`

- 건물 블록의 최소 도형 표현
- 충돌과 hitscan 판정 데이터는 기존 순수 로직이 소비

### `GameScene`

- 설정의 도로를 배경에 전달
- 설정의 장애물을 기존 방식으로 생성

## 현재 AI에 따른 제약

현재 Zombie는 별도의 pathfinding 없이 Player 방향으로 이동하고 장애물 표면에서
미끄러진다. 따라서 좁은 골목, 막다른 길, 실내 공간과 복잡한 오목 구조는 만들지
않는다. 중앙도로, 외곽 순환로와 연결도로가 복수의 단순 루프를 형성하며 각 건물은
독립된 직사각형으로 둔다.

## 테스트

- 모든 건물이 고정 맵 경계 안에 존재
- Player 시작 원이 건물과 겹치지 않음
- 중앙 가로·세로 통로가 Zombie 지름보다 충분히 넓음
- 외곽 순환로와 개방된 주차장 존재
- edge spawn을 방해하지 않는 외곽 여백
- 기존 충돌 및 hitscan 테스트 유지

## 제외

- 랜덤 또는 절차적 맵 생성
- 실내 진입, 문과 창문
- 파괴 가능한 구조물
- 재질별 관통
- 충돌하는 차량 및 소형 장애물
- 내비게이션 메시와 pathfinding
- 정식 타일셋, 텍스처 및 이미지 에셋
