# Zombie Horde

Phaser 3와 TypeScript로 개발하는 2D 탑다운 좀비 생존 게임입니다.

## Play

[zombie-horde.neuma573.com](https://zombie-horde.neuma573.com/)

PC와 모바일 브라우저를 지원하며, 모바일은 세로와 가로 화면에서 모두 플레이할 수 있습니다.

## Controls

### PC

- `WASD`: 이동
- 마우스: 조준
- 마우스 왼쪽 버튼: 공격 (화기 발사 / 근접 무기 휘두르기)
- `R`: 재장전
- `Space`: 조준 방향으로 좀비 밀치기
- `1`, `2` 또는 화면의 무기 슬롯 아이콘 클릭: 무기 전환
- `E`: 가까운 보급 상자 열기 / 무기 슬롯이 모두 찼을 때 가까운 바닥 무기로 현재 무기 교체 (보급 상자 열기 우선)
- 바닥 무기에 마우스 올리기: 무기 정보 확인
- 마우스 휠: 화면 확대·축소
- `Esc`: 일시정지 메뉴 열기 / 게임 재개
- `Enter` 또는 클릭: Game Over 후 재시작

### Mobile

- 왼쪽 가상 스틱: 이동
- 게임 화면 터치 및 드래그: 조준
- `FIRE`: 공격 (화기 발사 / 근접 무기 휘두르기)
- `R`: 수동 재장전
- `PUSH`: 조준 방향으로 좀비 밀치기
- 화면의 무기 슬롯 아이콘 터치: 무기 전환
- `OPEN`: 가까운 보급 상자 열기 (열 수 있는 거리에서 버튼 표시)
- 가까운 바닥 무기 터치: 무기 획득 / 슬롯이 모두 찼으면 현재 무기 교체
- 게임 화면에서 두 손가락을 벌리거나 오므리기: 화면 확대·축소
- 일시정지 버튼: 메뉴 열기 (`RESUME`으로 게임 재개)
- 화면 터치: Game Over 후 재시작

탄창이 비고 예비 탄약이 남아 있으면 모바일에서는 자동으로 재장전합니다.

PC와 모바일 모두 빈 무기 슬롯이 있으면 가까이 다가간 바닥 무기를 자동으로 획득합니다. 탄약과 회복 아이템도 가까이 다가가면 사용할 수 있는 상태에서 자동으로 획득합니다.
